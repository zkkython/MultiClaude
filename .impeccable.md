## Design Context

### Users
Primary users are heavy CLI developers who run multiple LLM coding agents in parallel. They use this app in high-frequency development sessions to launch, switch, and manage isolated terminal workflows quickly and reliably.

### Brand Personality
Hacker-like, sharp, trustworthy.
The product should feel fast and confident under pressure, with clear system feedback and no ambiguity in critical actions.

### Aesthetic Direction
Dark geek aesthetic is the default direction.
Keep the interface focused and technical, avoid flashy decorative motion, and avoid generic AI-template visuals.

### Design Principles
1. Speed-first interaction: prioritize low-friction, high-frequency actions and clear action hierarchy.
2. Sharp clarity: make status, risk, and next actions immediately scannable.
3. Trust by feedback: every important action should have deterministic, visible system response.
4. Minimal but intentional motion: use motion only for state transition clarity, not decoration.
5. Accessibility baseline: target WCAG AA and support reduced-motion by default.
